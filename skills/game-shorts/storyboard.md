# 分鏡：鉤子、beat sheet、字卡

做法來自 2026-10 的研究（創意結構、預告片剪輯師的流程、連結貼文與爆紅案例）；**比例、門檻、案例數字在研究文件「素材與短影音 › 短影音製作」分頁**。

## 鉤子（第一拍到第二拍）

第一格就要有東西在動、有懸念；不放 logo、不放標題卡。常用的幾種，挑跟遊戲最貼的：

| 鉤子 | 怎麼開 | 適合 |
|---|---|---|
| 懸念 | 停在「下一秒會怎樣」的那一格，字卡問「這台會落地嗎？」 | 結果要等一下才揭曉的遊戲 |
| 問句 | 「一出發就按噴射會怎樣？」，接著直接給答案 | 有荒謬後果的錯誤按法 |
| 失敗 | 第一格就撞爛 | 物理、難度遊戲；失敗本身好看 |
| 差一點 | 看起來快成功了才出錯 | 想讓觀眾覺得「我做得到」 |
| 教學 | 「4 個時機不再摔車」 | 規則少、時機難的遊戲 |
| 前後對照 | 第 1 次 vs 第 N 次 | 有真實進步數據時才用 |

**挑失敗片段的準則**：看起來「本來應該做得到」的失敗，比一開始就沒救的失敗更能讓人想自己試（研究文件有出處）。
所以先放「差一點」，全毀的大場面留到中段當高潮。

## Beat sheet

鏡頭長度用拍寫（BPM 120 時一拍半秒、一小節兩秒），一個鏡頭只講一件事。兩份起手範本：

**短（約 30 拍）：差一點 → 轉成功**

| 拍 | 畫面 | 字卡 | 聲音 |
|---|---|---|---|
| 0–6 | 快成功的那一局，觸地對齊第 6 拍 | 鉤子問句；下面一行小字講玩法 | groove，第 5.5 拍全停 |
| 6–10 | 同一局接著播：撞地、零件噴飛（遊戲自己的慢動作） | 真實的慘烈度數字跳上來 | 撞擊落在 drop |
| 10–18 | 兩種不同的錯法各 4 拍，白閃切入、拉近 | 錯在哪（小字）＋數字 | whoosh 切點、各自的撞擊 |
| 18–28 | 成功的那一局（標「示範」），觸地對齊 drop | 「其實可以這樣」→ 分數 | break 墊底，riser 爬到觸地 |
| 28–34 | 片尾卡 | 一句挑戰＋CTA＋網址 | outro |

**中（約 50–60 拍）：失敗蒙太奇 → 最接近的一次 → 成功**：開頭直接撞爛 → 一鏡帶出玩法 → 4–6 種死法各 3 拍、數字跳號 →
最接近成功的一次放慢 → 成功一鏡到底不剪 → 分數榜切到慘烈度榜 → 片尾卡。

每支片的分鏡至少包含：鉤子在第一拍就出現、前三秒講清楚「這是在玩什麼」、有一次以上的節奏變化（變速、凍結、全停）、結尾有 CTA。

## 字卡

- **一張字卡一件事**，能用畫面說的就不用字；強調一兩個詞（`**…**` 上強調色）。
- 放在畫面上方約 15%–60% 之間：上方與下方是平台的介面（帳號、說明文字、按鈕列），右側是按讚那一欄。精確範圍看研究文件。
- **不要疊到遊戲自己的字**（例如落地時的評語大字）：先抽關鍵幀看它在哪，字卡讓開。
- 數字跳動（counter）要留夠時間跳完再切；「慘烈度」「分數」這種標籤用遊戲自己的詞。
- 即時的數字（高度、速度）讀核心狀態，可以補畫面上看不出的尺度感（往上衝時背景只有星星）。
- 字卡的字放在分鏡 JSON，**各語系一起寫**；缺語系就報錯，不默默用別的語系。

## 聲音

- 先定 BPM，鏡頭長度與切點都用拍，對齊才不用事後微調。
- 張力：撞擊前半拍全停（stop＋唱盤煞車音）→ 撞擊落在 drop；成功落地前用 riser 爬升。
- 每個切點一個 whoosh 或白閃；遊戲自己的音效保留（引擎、噴射、撞擊），配樂只是墊底。
- 片子要在靜音下也看得懂（字卡＋畫面），開聲音時更好看。

## 概念清單

一次準備 3–5 個差異明顯的概念，每個寫一句鉤子＋分鏡大綱＋借了哪個手法。一款物理賽車小遊戲的第一批：

1. 差一點：快成功卻摔爛 → 兩種錯法 → 完美落地（懸念＋失敗轉成功）
2. 一出發就按噴射會怎樣？：直衝天際再掉下來（問句＋荒謬場面）
3. 4 個時機不再摔車：照完美局真實的作動時間下字卡（教學）

之後可做：本週最慘三摔（用真實玩家的重播，車門上的暱稱換掉）、第 1 次 vs 第 N 次（要有真實紀錄）、
devlog 式「我做了一個車子自己開、但幾乎沒人落得了地的遊戲」（有真實比例才寫「幾乎沒人」）。
