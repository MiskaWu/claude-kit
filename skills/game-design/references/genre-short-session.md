# 短局網頁小遊戲（一局約 60 秒）

2026-10-21 研究整理；原始筆記 `research/notes_C_genres.md` A 節。標【推論】的是把來源搬到這類遊戲的整合，最需要試玩驗證。
打磨畫面與回饋的迴圈在 game-polish；推出去（分享卡、第二局率的量法、短連結）在 game-publish。

## 體驗核心

一個動詞，立刻有回報，結局是一件能拿出去給人看的東西。

- Voodoo 的 Selz 五條準則【一手】https://www.gameanalytics.com/blog/voodoo-guide-mobile-game-design-keep-things-simple ：
  snackable（「the session length is short and gives a lot of reward」）、intuitive（「players can understand them in a few seconds」）、
  Youtubable、forgiving（Roller Splat「you can't even die」；反對熔岩、流沙這類一碰就死的危險物）、gameplay first（「The visuals come second.」）。
- Juul《The Art of Failure》【學術】：失敗讓人覺得「我不夠好」，玩家為了擺脫這種感覺再玩一局。所以失敗要能歸因到自己。
- Wordle【訪談】：emoji 方格原本是玩家自己手打的，Wardle 把它做成內建：不暴雷、可以炫耀；刻意不放連結（覺得連結「trashy」，沒有方格的神祕感）；
  一天一題是為了「leave people wanting more」。

## 要注意

1. **前三秒**＝一個動詞、一個目標、一個看得見的回饋，不先講規則。超休閒發行商的 CPI 測試其實在測「看一眼就懂、想玩」。
   網頁沒有廣告漏斗，對應的量法是第一次有效輸入的時間、第一局完成率【推論】。
2. **再一局三要素**：重來零摩擦、失敗能歸因、差一點就成功【推論，依 Juul】。嚴苛可以（Flappy Bird 作者自己愈玩愈好就一路調難【二手】），
   前提是重來是瞬間的、死因一眼看得出來。雷區是懲罰重加上死因不明。
3. **60 秒也走一次起承轉合**：介紹動詞 → 加壓或變奏 → 一個意外 → 收尾揭曉。同一個節奏撐滿 60 秒，第 30 秒就膩【推論，依林田】。
4. **沒有失敗條件的玩具型**：張力只能來自限制（時間、資源、面積）和最後的揭曉；結局的成品要看得出「我這一個」的獨特之處（風格標籤、稀有度、跟別人比）【推論】。
5. **推運氣型**（抱或跑、全押）：價格若是純隨機漫步，玩家手上沒有資訊，「跑」就是猜硬幣，最佳解退化成固定第 N 秒跑。
   要在決定之前給看得到的訊號（input randomness），而且最後的爆倉或暴富要誇張好笑，失敗變笑點【推論，依 Burgun】。
6. **時機型**：判定窗與物理結果要穩定。同樣的輸入出現不同結果，玩家就學不會，也不會再來一局【推論】。
7. **分享物**：沒有上下文也看得懂、不暴雷、每人不同，引起「我也要試」【訪談：Wardle】【推論】。

## 常見失敗

| 失敗 | 為什麼 |
|---|---|
| 第一局先跳教學文字 | 違反幾秒內就懂（Selz） |
| 死了要點好幾下、看過場才能重來 | 重來摩擦殺掉再一局 |
| 死因看不出來（隨機陷阱、畫面外、判定太寬或太窄） | 失敗無法歸因（Juul） |
| 同一個節奏撐滿全場 | 沒有起承轉合 |
| 最佳策略退化（固定時間按、永遠全押） | 玩家會把樂趣優化掉（Johnson） |
| 分享卡只有一個分數 | 沒有個性，沒有「我也要試」的鉤子 |
| 元素太多、聲光太吵 | Selz 警告玩家會受不了 |
| 核心手感還不對就先做美術 | gameplay first |

## 怎麼量

自動玩家（人設與固定種子照 game-polish 的 `rules-layer.md`）：
- 局長分布、第一次失敗發生在第幾秒、失敗位置。
- 技巧天花板：亂玩、簡單規則、最佳化三種的分數差。
- 運氣佔比：同一策略換種子的分數變異。
- 退化策略：最佳化找到的是不是無聊的策略。推運氣型看「抱」和「跑」的期望值曲線會不會隨盤面訊號改變；某個時間點後永遠該跑，就不是決定。

只有真人看得到：
- 不給說明，第一個輸入什麼時候發生、對不對。
- 失敗那一刻是笑、「啊差一點」，還是罵。
- 不提示會不會自己按再一局；連續玩了幾局。
- 會不會截圖、轉傳、念給旁邊的人聽；旁觀的人想不想接手。
- 分享卡給沒玩過的人看，看得懂嗎、想點嗎。

## 門檻數字（只當量級感）

公開的只有 app 加廣告情境的超休閒數字，都是 2019–2021 年：
- Voodoo【一手：發行商自述】：舊經驗法則 D1 55%、D7 22%、CPI < $0.25，後來降為 D1 45%、D7 13%、CPI $0.20；評分也看遊玩時間、勝率、一局長度。
  反例：Aquapark.io 的 D7 只有 17%，卻是 2019 年下載量第一。
- Supersonic【一手：發行商自述】：CPI < $0.30、Android D1 ≥ 38%、平均每人 D7 遊玩秒數 > 2000。

網頁小遊戲（非 app store）的公開留存與再玩率基準本輪沒找到。
