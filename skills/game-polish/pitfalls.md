# 踩過的坑

開工前掃一遍；踩到新的就補一條（寫症狀、原因、解法）。

## 巡覽與截圖

- **無頭瀏覽器預設語系是英文。** `newContext`／`newPage` 沒設 `locale`，截到的永遠是英文，會誤以為其他語系缺字。每個 context 都設。
- **點了按鈕之後焦點還在按鈕上**，下一個空白鍵被按鈕吃掉（「點了開始之後空白鍵沒反應」）。
  遊戲開局時 `blur()`；鍵盤處理跳過 input／button 上的事件；巡覽腳本點完按鈕要再按一次遊戲鍵，確認遊戲真的收到。
- **假時鐘不推 CSS 動畫與 setInterval 以外的東西。** `page.clock.install()` 加 `runFor` 能快轉 JS 計時與 rAF，
  但 CSS 動畫照真實時間走：截圖前 `waitForTimeout` 等一下，不然截到動畫半途。要看「兩面切換」這類效果，用真實時間跑。
- **單一語系的自動玩家判斷**：讀除錯字樣決定按哪顆時，用跟語系無關的特徵（例如「答案 B：原因」有冒號、「答案 A」沒有），`--locales` 才不會亂按。
- **用真實時間玩的巡覽不是確定的**：桌機和手機按下去的毫秒會差一點，結算數字不同是正常的；要比數字用核心的自動玩家或固定輸入。
- **巡覽全跑四個語系很久**（實測一款四語系的小遊戲要 10 分鐘以上），Bash 有 10 分鐘上限：分語系跑，或放背景。
- **只截靜態畫面抓不到流程 bug**：Svelte 5 的 `$state` 會把物件包成 proxy，拿「存進 state 的物件」和原物件比 `===` 永遠是 false，
  曾有一款因此卡在「成績上傳中」（改成每局發流水號來對）。要跑一次完整的上傳／結算流程，不只截圖。

## 單檔版（claude.ai Artifact）

- 用 `file://` 開之前，先包上平台發佈時會加的外框（`<!doctype html>`、charset、`viewport-fit=cover`、`[hidden]{display:none!important}`），畫面才跟線上一致。
- **嵌在 iframe 裡要先點一下畫面鍵盤才收得到**：畫布 `pointerdown` 時 `window.focus()`，說明寫「先點一下畫面」。
- **Artifact 的 CSP 擋掉對外 fetch**（例如作品站的 `news.json`）：拿不到要安靜退回，不能報錯，也不能讓紅點之類的狀態壞掉。
- 試玩版通常是離線模式：排行榜、上傳、伺服器版本號這些只在正式站驗得到。

## 版面與樣式

- 全域的 `canvas { position: fixed; inset: 0 }` 把面板裡的預覽畫布也撐成全螢幕，蓋住所有按鈕。全螢幕樣式只給遊戲畫布的 id。
- 直放的手機不要整個擋掉，給一行「橫放畫面更大」就好。
- 從按鈕往上飄的數字會壓到上方卡片的字：從按鈕內部起飄、在越界前淡掉。
- 兩個提示疊在同一處（換段提示和事件大字、對話框）：換段提示移到不擋主角與主要物件的位置。

## 寫檔

- 用寫檔工具寫入含 `\u2028`、`\u200b` 這類跳脫序列的原始碼時，跳脫序列可能被換成**真的隱形字元**（U+2028 會把正規表示式切斷，
  也會被部分工具當成換行）。寫完 `grep -nP '[\x{2028}\x{2029}\x{200b}-\x{200f}\x{feff}]'` 檢查一次，或改用 `String.fromCharCode`。
  寫文件時提到這兩個字樣也一樣會被換掉（polish-playbook.md 和這份手冊都中過），寫完 Markdown 也要檢查。
